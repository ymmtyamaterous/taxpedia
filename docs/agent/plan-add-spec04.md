# 実装計画: add-spec04 バグ修正・追加仕様・懸念事項対応

## 概要

`docs/user/add-spec04.md` の内容をもとに、バグ修正・追加仕様・懸念事項への対応を実施する。

---

## 現状分析

### バグ原因

- `/app/courses/page.tsx` は Next.js の **Server Component**（`export const dynamic = "force-dynamic"` 付き）
- サーバーサイドのフェッチでは `NEXT_PUBLIC_API_BASE_URL` が未設定の場合 `localhost:8080` にフォールバックするが、本番環境では Next.js サーバーからバックエンドコンテナに到達できないケースがある
- エラーハンドリングがなくフェッチ失敗時にページ全体がクラッシュする
- 用語辞典 (`/app/glossary/page.tsx`) はすでに `"use client"` + `useEffect` でクライアントフェッチしており、同様のサーバーエラーが起きうる（エラーは `catch(() => setTerms([]))` で握りつぶされているため画面は壊れないが空になる）

### フッター現状

- `/app/page.tsx` のフッターリンクがすべて `href="#"` のダミーリンク
- 利用規約・プライバシーポリシーページが存在しない
- お問い合わせ・運営会社のリンク先が未設定

---

## 実装タスク一覧

### 1. バグ修正: コース一覧のサーバーエラー修正

**対象ファイル**: `frontend/app/courses/page.tsx`

**変更内容**:
- Server Component から **Client Component** に変換（`"use client"` を追加）
- `useState` + `useEffect` でクライアントサイドフェッチに変更（用語辞典ページと同様のパターン）
- ローディング状態とエラー状態のハンドリングを追加
- `export const dynamic = "force-dynamic"` を削除

---

### 2. フッターリンクの調整

#### 2-1. 利用規約ページの追加

**追加ファイル**: `frontend/app/terms/page.tsx`

**内容**:
- ヘッダー付きのシンプルな利用規約ページ
- テンプレートコンテンツ（「現在準備中です」等）を配置

#### 2-2. プライバシーポリシーページの追加

**追加ファイル**: `frontend/app/privacy/page.tsx`

**内容**:
- ヘッダー付きのシンプルなプライバシーポリシーページ
- テンプレートコンテンツ（「現在準備中です」等）を配置

#### 2-3. フッターリンクの実リンク化と環境変数対応

**対象ファイル**: `frontend/app/page.tsx`

**変更内容**:
- 利用規約: `href="/terms"` に変更（`<Link>` コンポーネントへ）
- プライバシーポリシー: `href="/privacy"` に変更（`<Link>` コンポーネントへ）
- お問い合わせ: 環境変数 `NEXT_PUBLIC_CONTACT_URL` のリンクを設定（未設定時は非表示）
- 運営会社 → **運営者**: 環境変数 `NEXT_PUBLIC_OPERATOR_URL` のリンクを設定（未設定時は非表示）

**追加環境変数** (`infra/.env.sample`):
```
NEXT_PUBLIC_CONTACT_URL=""
NEXT_PUBLIC_OPERATOR_URL=""
```

---

### 3. 生成AIコンテンツの注意書き追加

**対象ファイル**: `frontend/app/lessons/[id]/lesson-viewer.tsx`（または同ディレクトリの page.tsx）

**変更内容**:
- レッスンコンテンツ表示部分の下部に以下のような注意書きコンポーネントを追加
  ```
  ⚠️ このコンテンツは生成AIによって作成されています。内容の正確性については十分ご確認ください。
  ```
- スタイルは既存の TailwindCSS クラスを使用

---

### 4. モバイルでのマイページ導線追加 / ヘッダーのレスポンシブデザイン改善

**対象ファイル**: `frontend/components/header.tsx`

**変更内容**:
- モバイル画面（`md` ブレークポイント未満）でハンバーガーメニューを追加
- メニュー開閉状態を `useState` で管理
- ハンバーガーメニュー内の項目:
  - ログイン前: コース・用語辞典・ログイン・無料で始める
  - ログイン済み: コース・用語辞典・**マイページ**・ログアウト
- デスクトップ（`md` 以上）は現在の表示を維持
- ログイン前のデスクトップヘッダーも確認し、はみ出し等があれば調整

---

### 5. ログイン済みユーザーのLP表示問題対応

**対象ファイル**: `frontend/app/page.tsx`

**変更内容**:
- LP ページを `"use client"` に変換（または既存の `useAuth` 利用）
- `useAuth` でログイン状態を取得し、以下を制御:
  - ログイン済みの場合: 「登録なしで遊ぶ」「登録なしで今すぐ学ぶ」「アカウント登録」等のボタン文言を変更または非表示
  - 「無料で始める」「進捗を記録したい」等の新規登録リンクをログイン済みの場合は「マイページへ」等に変更
  - CTA セクションの「アカウント登録して進捗を記録」ボタンも同様に制御

> **注**: ログイン後にLPへのリダイレクト（`/` → `/courses`）は `auth-provider.tsx` または各ページで実装する。今回は LPのコンテンツ制御のみ実施し、リダイレクトは別途検討とする。

